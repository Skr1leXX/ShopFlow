# Демонстрация ShopFlow

Сценарий на 10–15 минут для показа заказчику. Все данные вымышленные: аккаунты на домене `.demo`, телефоны `+7 555 …`, адреса условные.

## Подготовка демо-стенда

1. Создайте **отдельную** базу Turso для демо ([README → Настройка Turso](../README.md#настройка-turso)) или используйте локальный файл (`TURSO_DATABASE_URL=file:local.db`).
2. Заполните `.env.local` (`TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN` для облака, `DEMO_PASSWORD=<придуманный пароль>`).
3. Выполните:
   ```bash
   npm run db:setup      # схема и каталог из 34 товаров
   npm run seed:demo     # демо-аккаунты, адреса, избранное и 8 заказов
   ```
4. Запустите сайт (`npm run dev` или опубликованный на Vercel).

### Демо-аккаунты

| Роль | Email | Что показывает |
|---|---|---|
| Администратор | `admin@shopflow.demo` | полная админ-панель |
| Покупатель | `anna@shopflow.demo` | 3 заказа в разных статусах, адрес, избранное |
| Покупатель | `ivan@shopflow.demo` | заказы «Собирается», «Отменён» |
| Покупатель | `maria@shopflow.demo` | доставленный заказ с промокодом, избранное |

Пароль — значение `DEMO_PASSWORD` (или тот, что напечатал `seed:demo`). **Не публикуйте пароль администратора** на открытом демо-стенде: любой посетитель сможет менять данные. Для публичного показа дайте только покупательский аккаунт, а администратора показывайте с экрана.

Промокоды из каталога: `WELCOME10` (10%, от 3 000 ₽), `SPRING500` (500 ₽, от 5 000 ₽, лимит 200), `VIP20` (20%, от 8 000 ₽, лимит 50).

## Сценарий показа

### 1. Витрина (гость), ~3 мин
1. Главная: баннер, категории, рекомендации, новинки, спецпредложения.
2. Каталог → фильтры слева: категория, цена, размер, цвет, бренд; сортировка; поиск «пальто» (ищет по названию и описанию). Ссылка с фильтрами копируется и открывается как есть.
3. Карточка товара: галерея, выбор цвета и размера. Размеры без остатка недоступны, под размером видно «Осталось N шт.».
4. «В корзину» без входа: корзина сохраняется в браузере. Обновите страницу — товары на месте.

### 2. Регистрация и вход, ~2 мин
1. «Войти и оформить заказ» → «Регистрация». Подтверждения по почте нет: после регистрации пользователь сразу вошёл.
2. После входа гостевая корзина переносится в базу (проверьте значок корзины и вторую вкладку под тем же аккаунтом).
3. Личный кабинет → «Профиль» → «Смена пароля» (нужен текущий пароль). Восстановления пароля по почте нет.

### 3. Оформление заказа, ~3 мин
1. В корзине измените количество (нельзя больше остатка), примените `WELCOME10`.
2. Оформление: контакты, способ доставки (стоимость пересчитывается), адрес, оплата. Видна пометка: **оплата демонстрационная, деньги не списываются**.
3. «Подтвердить заказ» → страница заказа. Двойной клик по кнопке создаёт один заказ.
4. Личный кабинет → «Заказы»: состав, итог, статус; «Избранное», «Адреса», «Профиль».

### 4. Админ-панель, ~5 мин (войдите как `admin@shopflow.demo`)
1. **Dashboard:** выручка, средний чек, график за 30 дней, популярные товары, низкие остатки.
2. **Заказы:** найдите свой заказ по номеру, откройте, смените статус на «Подтверждён», затем «Собирается». Отмена возвращает товар на склад (посмотрите журнал на странице «Склад»).
3. **Склад:** проведите приход и списание, попробуйте списать больше остатка: операция отклонится. В «Истории движения» видны все изменения, включая продажи.
4. **Товары:** создайте товар, загрузите фото (Vercel Blob, нужен `BLOB_READ_WRITE_TOKEN`; без него вставьте ссылку на фото), добавьте размер/цвет с остатком, скройте товар — он пропадёт с витрины. Удаление — через окно подтверждения.
5. **Категории:** изображение, порядок стрелками. **Промокоды:** создайте код со сроком и лимитом.
6. **Экспорт:** CSV товаров и заказов (кнопка «CSV» с учётом фильтров).
7. Покажите защиту: под покупателем откройте `/admin` — доступ закрыт.

## Что работает по-настоящему, а что демонстрационное

| Функция | Статус |
|---|---|
| Регистрация, вход, выход, смена пароля | Реально: собственная реализация (scrypt, серверные сессии). Писем и восстановления пароля нет |
| Роли и разграничение доступа | Реально: проверка сессии и роли на сервере в каждом запросе и действии (RLS в SQLite нет), проверено тестами |
| Каталог, поиск, фильтры, сортировка | Реально: запросы к базе |
| Корзина (гость и пользователь), слияние при входе | Реально |
| Создание заказа, цены, остатки, промокоды | Реально: транзакция `placeOrder`, атомарно, с защитой от повторов |
| Админ-панель, склад, журнал, CSV | Реально |
| Загрузка фото | Реально при `BLOB_READ_WRITE_TOKEN` (Vercel Blob); без токена отключена |
| **Оплата** | **Демо.** Платёжный провайдер не подключён, деньги не списываются. Заказ создаётся как «Новый» |
| **Доставка** | **Демо.** Стоимость считается по простому правилу (курьер 490 ₽, почта 290 ₽, самовывоз и заказы от 15 000 ₽ бесплатно). Служб доставки, трекинга и расчёта по адресу нет |
| **Письма** | **Нет.** Ни подтверждения, ни уведомлений о заказе, ни восстановления пароля |
| **Демо-заказы** | Созданы тем же кодом, что и настоящие; остатки и журнал склада согласованы, даты сдвинуты назад |
| Фото товаров | Ссылки на Unsplash; соответствие снимка товару ориентировочное |
| Раздел «Настройки» админки | Только чтение |

## Если что-то не работает на показе
- «Подключите базу данных» вместо сайта — не задан `TURSO_DATABASE_URL` (`npm run check:env`).
- Нет товаров — не выполнен `npm run db:setup`.
- Не входит под демо-аккаунтом — не выполнен `npm run seed:demo` или пароль не совпадает с `DEMO_PASSWORD`.
- Загрузка фото пишет «не настроена» — не задан `BLOB_READ_WRITE_TOKEN`.
- Картинки не грузятся — нет доступа к Unsplash или хост не добавлен в `images.remotePatterns` (`next.config.ts`).
