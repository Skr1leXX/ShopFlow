# E2E-тесты (Playwright)

Сценарии с данными работают против **настоящего проекта Supabase** (облачного или `supabase start`) с применёнными миграциями. Без него выполняются только `smoke.spec.ts` (поведение без настроенного бэкенда), остальные помечаются как пропущенные.

## Запуск

1. Создайте отдельный тестовый проект Supabase, примените `supabase/migrations/*`. В Authentication → Providers → Email можно оставить подтверждение email включённым: тесты подтверждают пользователей через Admin API.
2. Задайте переменные (в `.env.local` или окружении):
   ```
   NEXT_PUBLIC_SUPABASE_URL=...
   NEXT_PUBLIC_SUPABASE_ANON_KEY=...
   SUPABASE_SERVICE_ROLE_KEY=...   # только для подготовки данных тестами; в приложение не попадает
   ```
3. ```bash
   npm run build
   npm run e2e            # все проекты: desktop, tablet, mobile
   npm run e2e:desktop    # только desktop
   npm run e2e:report     # открыть HTML-отчёт
   ```

Браузер: установленный Edge или Chrome (автоопределение), либо `E2E_BROWSER_PATH`, либо Chromium от Playwright (`npx playwright install chromium`).

## Данные

`global-setup` создаёт изолированные данные с префиксом `E2E` (2 пользователя, категория, 15 товаров, промокод), `global-teardown` удаляет всё созданное, включая заказы тестовых пользователей. Реальный каталог не изменяется. Не запускайте тесты на боевом проекте.

## Что покрыто

| Файл | Сценарии |
|------|----------|
| `auth.spec.ts` | регистрация, вход, выход, сессия после перезагрузки, ошибки входа, восстановление пароля, защита приватных страниц, open redirect |
| `catalog.spec.ts` | загрузка, пагинация, поиск (название, описание, спецсимволы), фильтры, сортировка, страница товара, 404 |
| `cart.spec.ts` | гостевая и серверная корзина, количество, остаток, удаление, сохранение, слияние при входе |
| `checkout.spec.ts` | обязательные поля, самовывоз, промокод, заказ, остатки, цена на момент покупки, двойной клик, подмена цены, нехватка товара |
| `admin.spec.ts` | доступ админа, блокировка пользователя, Dashboard, CRUD товаров/категорий/промокодов, фото, заказы и отмена, склад, CSV |
| `responsive.spec.ts` | mobile / tablet / desktop: переполнение, навигация, размеры элементов, фильтры, изображения, сетевые ошибки |
| `perf.spec.ts` | число запросов, вес JS, оптимизация изображений, кэш, заголовки, отсутствие секретов |
| `smoke.spec.ts` | поведение без Supabase, 404, заголовки безопасности, экспорт без входа |
